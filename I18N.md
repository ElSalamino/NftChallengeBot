# Localizzazione IT / EN / ES

Il bot, la Wiki e il Single Player Playtest supportano italiano, inglese e spagnolo.
L'italiano è la lingua di fallback.

## Uso nel bot

- La prima lingua viene ricavata da `message.from_user.language_code`.
- La scelta viene salvata nel profilo come `player[username]["lang"]`.
- I comandi `/lingua`, `/language` e `/idioma` aprono il selettore.
- Testo, caption, tastiere e risposte alle callback vengono localizzati dal client.

Oggetti (ingredienti inclusi), set, stanze, nemici, pet, meteo, scelte sceniche
e le altre entità hanno un ID stabile in `entities.json`. Il motore continua a
ricevere internamente i nomi italiani, mentre presentazione, Wiki e playtest
mostrano il nome localizzato. I backup
storici vengono letti senza migrazione manuale; al salvataggio, i campi entità
noti vengono serializzati come ID e riconvertiti in memoria al caricamento.
Se un nome italiano viene rinominato, il valore precedente può restare in
`aliases`: l'ID e i vecchi riferimenti non cambiano.

Gli URL della Wiki e i valori persistiti dal playtest usano gli ID. I vecchi URL
basati sul nome restano validi e vengono canonicalizzati automaticamente.
I `callback_data` Telegram restano tecnici e invariati per non rompere i flussi
attivi; il testo del pulsante viene comunque localizzato.

## Cataloghi

I file sorgente sono:

- `locales/it.json`
- `locales/en.json`
- `locales/es.json`
- `entities.json` (ID e nomi `it` / `en` / `es`)

Le chiavi esplicite e le traduzioni revisionate hanno la precedenza. Le altre
frasi ricevono una chiave stabile derivata dal testo sorgente. I placeholder
come `{0}`, `{bonus}` e `{turno.proc:pct}` devono essere identici nelle tre lingue.

Per rigenerare il bootstrap serve un traduttore CTranslate2 offline:

```bash
PYTHONPATH=/percorso/dipendenze python tools/bootstrap_i18n.py \
  --wiki-dir /percorso/wiki-generata \
  --it-en-model /percorso/modello-it-en \
  --en-es-model /percorso/modello-en-es
```

Il registro dei nomi si aggiorna separatamente e conserva gli ID e le revisioni
già presenti:

```bash
PYTHONPATH=/percorso/dipendenze python tools/bootstrap_entities.py \
  --it-en-model /percorso/modello-it-en \
  --en-es-model /percorso/modello-en-es
```

Senza `--force`, le traduzioni esistenti — incluse le revisioni umane — non
vengono sovrascritte.

## Verifica

```bash
python wiki/run_wiki.py --output /tmp/nft-wiki
python tools/audit_i18n.py --wiki-dir /tmp/nft-wiki
python tools/audit_entities.py
python playtest_web.py --self-test
```

Gli audit falliscono se manca una frase, una lingua, un placeholder, un ID, una
route o una conversione reversibile del salvataggio. Le stesse verifiche girano
in CI.
